# Public synthetic prototype artifacts

This repository serves explicitly public synthetic prototype releases on a separate origin from the experimentation platform. It contains generated assets only. Application source and restricted reference evidence live in their own private repositories.

Published paths under public/releases and public/manifests are retained. Add new content-addressed releases; never replace or remove older files. Serving availability depends on the repository, Pages configuration and account remaining available. This is not confidential artifact access control or a backup guarantee.

The versioned stage/check/verify operator lives in alastori/tidb-pm-prototypes/packages/prototype-artifacts. Every release is sealed and verified by exact file and tree digests. Only public/ is served. New publications must preserve all existing releases and pass anonymous byte verification after deployment.
